Guía Rápida para Desarrolladores

Bypassa meses de investigación de la API de Meta siguiendo este stepper estructural para configurar tu entorno de pruebas:

1

Crear App en Meta Developers

Entra a Meta for Developers, crea una App de tipo Negocios (Business) y agrégale el producto WhatsApp.

2

Configurar el Webhook en Meta

Apunta la URL del Webhook a tu servidor expuesto (ej. mediante Ngrok a http://localhost:3006/webhook). Usa como Verify Token el mismo que pongas en tu Sandbox. Suscríbete al campo messages y call_events.

3

Habilitar Números de WhatsApp

Obtén tu **Phone Number ID** y realiza una llamada de prueba desde tu móvil al número asignado por Facebook. El servidor capturará la llamada e iniciará la negociación WebRTC al instante.
